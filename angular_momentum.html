实验原理
装置：铁架台 + 悬挂钢球 + 下方金属圆盘。
过程：把小球拉开 θ₀ 释放 → 下摆 → 水平撞击圆盘边缘。
撞击方向角 φ：0° 小球沿圆盘切向擦击（角动量传递最大）；90° 沿半径正撞盘缘（对转轴无力矩，圆盘不加速，小球按恢复系数原路反弹）；中间角度为两种运动的叠加。
碰撞瞬间（冲量法求解）：
  · 接触点产生切向冲量 J，由恢复系数 e 确定
  · J = -(1+e)·(v₁-ω₀R) / (1/m + R²/I)
  · 小球：v₁′ = v₁ + J/m（冲量-动量定理）
  · 圆盘：ω′ = ω₀ - JR/I（反作用冲量）
  · 其中 I = ½·M·R² 为圆盘转动惯量
角动量守恒验证：
  · 碰前 L = m·v₁·R + I·ω₀
  · 碰后 L′ = m·v₁′·R + I·ω′
  · 面板显示 ΔL = L′−L ≈ 0（验证守恒）
碰撞后：圆盘绕竖直轴自由转动，小球反弹或嵌入。
